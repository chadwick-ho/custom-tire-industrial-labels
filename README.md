## Deployment and editing

GitHub Pages publishes the root of `main` to `www.cyjlabels.com`. Changes merged into `main` can affect the production site.

This repository currently contains static deployment artifacts, including HTML, images, CSS and compiled JavaScript. The audited tree does not include the original editable application or a `package.json`; there is no verified application build command in this checkout.

Preserve existing URLs, `CNAME`, `.nojekyll` and required runtime assets. Review changes on a branch, check consistency between HTML and client behavior, and verify links and mobile interactions before merging. Do not add unverified certifications, customer claims or performance promises.
