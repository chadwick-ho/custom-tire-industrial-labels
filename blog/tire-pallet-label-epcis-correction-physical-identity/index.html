Tire Pallet Labels: When to Keep the Code and Correct the EPCIS Event

Published November 17, 2026

A tire distributor checks a pallet’s printed SSCC against the physical unit and the packing record. The match is correct, but its trading partner reports an incorrect purchase-order reference on an EPCIS shipping event. Establish which layer contains the error before requesting a pallet label reprint.

Separate print evidence from the event correction

Have the shipping and receiving owners compare the readable label, the actual decoded identifier, the pallet contents reference and the stored event in an authorized review environment. If the wrong purchase order appears in the electronic event alone, preserve the physical identity while the event owner evaluates the correction. If the printed SSCC points to the wrong physical unit, quarantine the labeling exception and follow the parties’ label correction policy.

GS1’s EPCIS implementation guide shows an erroneous shipping event involving a wrong purchase-order reference. Its example records an error declaration and a corrective event. Have the system owner choose the appropriate procedure and check that the trading partner can see the correction against the intended unit. Store the affected event references and the physical verification together. A replacement sticker by itself cannot repair an already exchanged event.

GS1’s EPCIS and CBV Implementation Guideline, section 5.9 offers worked examples. The event correction workflow should be agreed with the parties that publish and use the records.

What to include in the approval record

Review pointEvidence to keep
Physical identityPrinted and decoded SSCC tied to the verified unit.
DiscrepancyActual versus expected event field and the record owner.
Partner witnessEvidence that the corrected record is visible to the intended receiver.
DispositionApproval to keep, hold or replace the physical label, with a reason.

Before approving the order

Hold if the unit-to-identifier match is disputed. A warehouse that does not exchange EPCIS events can still separate the label and the transaction, then use its own authorized correction workflow.

For tire barcode labels, send a redacted pallet label, approved identity fields, and which parts of the mismatch appear in print or in the record.
