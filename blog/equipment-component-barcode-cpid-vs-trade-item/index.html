Equipment Component Barcodes: Confirm Whether the Buyer Requires CPID or GTIN

Published November 16, 2026

An equipment OEM receives a component in an orderable service pack. One team wants a barcode for the part accepted into assembly. Another wants the identifier used to order the service pack. Approve which record each mark should resolve before the converter produces rolls for both.

Ask the identifier owner to name the object and receiving action

List the component, its orderable pack and any individual instance that needs traceability. Ask the customer for the approved identifier, its meaning, the required carrier and any permitted serial information. GS1’s CPID documentation addresses component or part identification in defined implementations. A GTIN identifies a trade item. Keep a customer part number and the assigned GS1 key in separate fields unless the approved data contract says how they relate.

Use authorized examples from the actual receiving system. Scan the component and service-pack proofs separately, compare the returned values to the approved data and confirm which record each scan should update. If both marks appear on the same assembly or pack, have the receiver identify which position and label it expects to read first. Preserve those instructions on the released drawings.

The GS1 Application Identifier directory lists separate fields for component or part identification and trade item identification. Use the buyer’s current system requirements and approved identifiers.

Review pointEvidence to keep
Physical objectComponent, orderable pack or individual instance.
SourceAssigned identifier and the party authorized to supply it.
Print requirementCarrier, readable text, placement and approved data fields.
Receiving witnessExpected record for each mark, checked on the real workflow.

Before approving the order

Hold if the purchaser only supplies the same numeric value for both marks without defining what either represents. A private part-number workflow can retain its approved data scheme.
