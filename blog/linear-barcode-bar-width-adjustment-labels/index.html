Linear Barcode Bar Width Adjustment: Qualify It on the Finished Label

Published November 8, 2026

The barcode file on a tire label looks clean, and a sample decodes the correct SKU. Under a print-quality review, however, its dark bars are wider than intended. The converter proposes bar width reduction. Ask which press and construction the adjustment represents before carrying it into a production master.

GS1 describes bar width adjustment in its barcode master image guidance. The adjustment compensates for a printing process that widens or narrows bars. That published process explanation does not set the reduction for your label. Use the current requirements for the receiving application when specifying symbol size and quality.

Keep the intended symbol size and data visible

A linear symbol represents information through its pattern of bars and spaces. In an approved compensation workflow, prepress generates the master using the required data and symbol specification, then applies a controlled adjustment to the bar edges for the process. Scaling the whole symbol changes the module scale and the space it needs on the label. Editing a screenshot gives the supplier no controlled source for either change.

Ask the converter to explain what output evidence showed a repeatable width deviation. Random voids, glare or a poorly defined source may require different corrective work. When a design has a small symbol and multiple compatible print routes, keep the approved master tied to the route that was qualified. A different material or print process can merit fresh evidence.

If prepress reports a compliant baseline without compensation, retain that record and review any proposed change through the same process. If the issue is an incorrect payload or an undersized symbol, address that choice with the data owner or art owner first. The barcode source guide describes the file handoff for regeneration.

For tire barcode labels, send the approved data, carrier and dimensions, source art and any available print-quality reports. Ask which master and representative finished sample will be used to approve the print route.
