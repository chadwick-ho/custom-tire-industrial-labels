Thermal Label Roll Trials: Check Where the Web Stops for Manual Tear-Off

Published November 14, 2026

A maintenance team prints asset labels as short batches and tears the finished web at the printer. Each print looks centered, but the last tear crosses the next usable label. Ask the operator to show where the web stops before changing the die or liner order.

Separate the printed position from the stop position

Confirm the intended delivery mode and the printer’s actual tear reference. With the approved job and roll, preserve a photo immediately after printing and before pulling the web. Identify the last printed label, next label, any intended perforation and the actual contact point at the tear bar. Witness one label and a typical short batch if the printer behaves differently between them.

Ask the equipment owner which adjustments, if any, are available on the installed model and whether the job can override them. Use its documentation and record the final settings. The converter should confirm tolerances for any gap or perforation. Approval should be based on a representative finished roll and a normal removal action, with the next label still available for the next job.

Zebra’s ZT411 and ZT421 user guide describes a tear-off setting for the documented printer family. The owner should confirm which control and mode apply to the installed device.

Before approving the order

Hold if the observed tear cannot stay within the intended location. A powered cutter or peel station uses a different delivery mechanism. Evaluate that option with its own media limits.

Related reading includes the powered cutter guide, the liner perforation guide, the minimum-feed-length check.

For industrial barcode qr code labels, send the printer model, roll drawing, intended tear position and a photo of the web at rest.
