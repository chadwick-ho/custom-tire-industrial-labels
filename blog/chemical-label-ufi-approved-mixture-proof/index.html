UFI on Chemical Labels: Get the Mixture Owner’s Approved Code Before Printing

Published November 15, 2026

An industrial chemical supplier adds an EU label version to an existing order. The new artwork has space for a UFI, but the printer has received only a trade name and an old safety data sheet. Before releasing that version, request the mixture owner’s approved identifier and instructions for its presentation.

Treat the code as controlled mixture information

Ask the responsible regulatory owner whether the product and intended use are within the UFI requirements. Request the exact code to print, its mixture or formulation reference and the active artwork revision. Keep each SKU-to-code mapping in a controlled handoff. A code copied from another pack or generated during artwork preparation does not establish the notification status of this mixture.

Have that owner approve the required location and legibility on the actual package. Review the complete label at finished size, including the UFI field and the surrounding information. Industrial-site uses and other special cases need the owner’s review of the relevant provisions before a printer decides where the information belongs. A supplier should receive a released print instruction rather than having to infer applicability from the container’s appearance.

ECHA’s guidance on generating and applying the UFI describes placement, the UFI prefix and the connection to a valid poison centre notification. Its special-case guidance should be reviewed for the actual use.

Review pointEvidence to keep
OwnershipRegulatory owner, intended market and applicability decision.
MappingExact supplied identifier, mixture reference and corresponding SKU or version.
ArtworkFinished size, approved placement and readable UFI prefix and value.
ReleaseOwner confirmation that the print instruction matches the active regulatory record.

Before approving the order

Hold the affected label version if its code or association is unresolved. When the owner confirms that this use has a different permitted information route, preserve that decision with the artwork. The printing approval does not establish that a notification has been made.

For chemical labels, send the regulatory-approved artwork, exact identifier mapping, package dimensions and quantity by version.
