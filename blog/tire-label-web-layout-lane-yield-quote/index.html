Tire Label Quote Layout: Check Whether a Width Change Adds a Lane

Published November 8, 2026

A buyer is finalizing a tread label and asks whether removing a few millimetres of unused face width might affect the quote. A narrower label can leave the number of positions across a production web unchanged, or it can cross the threshold to fit another lane. Ask for the feasible layouts before accepting a design compromise.

Compare the repeatable width, not the stock roll alone

On a production web, the converter needs space for the repeat pattern and any applicable trim, process marks, gutters, bleed or converting allowances. Esko's digital print workflow documentation describes width, gaps and repeat parameters in step-and-repeat layouts. The actual allowed width and arrangement depend on the converter's proposed process and the approved orientation.

Ask for a simple across-web layout for each design. For a straight layout with equal face widths and equal gutters, the occupied width can be illustrated as the number of lanes times face width, plus one gutter between each pair of adjacent lanes. Confirm which allowances belong inside that figure and which are already excluded from the usable width.

Work a hypothetical threshold

Assumed layoutAcross-web result
150 mm usable, 51 mm face, 3 mm guttersThree lanes require 159 mm. Two lanes fit this simplified example.
150 mm usable, 48 mm face, 3 mm guttersThree lanes require 150 mm in the simplified example.
Release basisObtain a proposed drawing, finished roll specification and quote revision for each option.

These figures are hypothetical and omit press-specific constraints. At an exact arithmetic fit, tolerance and required margins still need the converter's approval. A third lane changes the number of label positions across the repeated web, but total job economics also depend on stock usage, setup, tooling, slitting, yield and quantity by SKU. Ask for revised prices and delivered counts before comparing.

Keep the approved artwork readable at the alternate width. Preserve the intended barcode, clear area and usable tread contact. If the narrower design crosses a dispensing or placement limit, keep the original width and review the quotation on that basis. The feed pitch guide covers a separate calculation along a finished roll.

For custom tire label quotations, send the approved width range, orientation, artwork, quantities by SKU and finished-roll requirements. Ask whether the width alternatives change the feasible production layout or the quoted deliverable.
