Square or Rectangular GS1 DataMatrix for a Narrow Equipment Label?

Published November 14, 2026

An equipment buyer already has a GS1 DataMatrix requirement but only a narrow strip remains after the rating information is placed. The supplier proposes a rectangular symbol. Before changing the artwork, confirm which symbol shapes the receiving application allows and whether the real payload fits at the required size.

Compare footprints on the released panel

Get the approved data content, application requirements and usable dimensions from the respective owners. Have the label designer generate the two candidate shapes for that same payload using the intended workflow. Compare each footprint including the quiet zone, with room for nearby text and any placement tolerance. A narrow silhouette alone says little about data capacity or the printed module size.

Ask whether each shape is permitted by the applicable specification and by the receiver’s equipment and software. Generate rather than stretch the selected symbol. Proof representative records, including payloads most likely to require more modules, then verify the printed output as required and test the installed scan position. A scanner setting, code quality result and layout constraint can each reject a candidate for a different reason.

The GS1 DataMatrix guideline shows square and rectangular shapes and explains that exact symbol size depends on encoded content. Check the governing application rules before ordering.

Review pointEvidence to keep
DataApproved payload, receiving specification and representative longest cases.
DrawingAvailable width, height, clear border and neighboring objects.
CandidatesGenerated shape and measured full footprint at the intended module size.
AcceptanceRequired verification evidence and a read test with the installed device.

Before approving the order

Hold if the shape is disallowed or if fitting it requires removing clear space or distorting modules. Consider an approved placement or layout change with the data owner. Where the receiver specifies a different carrier, start by resolving that requirement.

Related reading includes the carrier choice for small parts, the quiet-zone design guide.

For industrial barcode qr code labels, send the usable panel drawing, required symbol and payload, and the reader or receiving specification.
