QR Labels With Non-English Text Need a Decoded-Text Witness

Published November 19, 2026

A local maintenance workflow stores short approved text directly in a QR label. The readable legend includes an accented product name, but one reader returns different characters from another. Confirm the payload encoding and the reader interpretation before changing the visible label wording.

Keep visible text and recovered text as two observations

Have the data owner release the exact raw-text payload and its intended character encoding. Ask the encoder owner how it represents that text and whether it supplies an Extended Channel Interpretation where the chosen QR implementation supports it. Identify the scanner or application paths that must recover the text. Different devices can use different interpretation rules, so retain actual outputs from the required paths.

Use harmless witness records covering the character families permitted in this order and a basic ASCII control. Compare the recovered characters and the application’s stored value with the approved source. A successful decode or a correctly printed visible name does not establish this correspondence. If the system instead uses a controlled web locator or a short internal ID, approve that architecture and its relationship to the equipment record before changing the payload.

Seagull documentation on the ECI protocol describes international character encoding and QR support in that product. Confirm the actual encoding and reader support in the project.

What to include in the approval record

Review pointEvidence to keep
PayloadExact source text and whether the QR contains raw text or a locator.
EncodingEncoder reference, character encoding and any ECI handling.
ReadersRequired device and application outputs retained exactly.
ReleaseCompared source, recovered characters and stored record.

Before approving the order

Hold if a required reader silently changes a character. A code containing only an approved basic identifier can retain its simpler data contract. This check does not approve translations or required equipment wording.

For industrial barcode qr code labels, send the approved raw-text witness, encoder reference, reader models and intended printed size.
