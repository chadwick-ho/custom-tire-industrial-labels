Thermal Transfer Ribbon Width: Measure the Full Label Web

Published November 8, 2026

A buyer orders a new roll of blank asset labels for a thermal transfer printer. The ribbon is wider than the printed serial line and the die-cut label, yet the backing extends beyond it. Before ordering a case of ribbons or changing the label, identify which width the printer instructions use.

The Zebra ZT231 and ZT231R user guide recommends a ribbon at least as wide as the media for the thermal transfer configurations it covers, to protect the printhead from wear. The model and its permitted configurations govern the purchase. The width of the dark image answers a different question about the artwork.

Put all three widths on one drawing

Label face width is the distance across the die cut. Web width is the delivered width across the continuous carrier, including the liner exposed beyond the face. Ribbon width refers to the ribbon specified for the printer. On a multi-lane web, use the width of the whole supplied carrier. Confirm that all measurements run across the feed direction.

What to recordEvidence to request
Finished webDimensioned drawing and a measured sample of the delivered liner.
Ribbon coverageCandidate ribbon width and the lateral relationship of ribbon and media in the installed machine.
Permitted supplyApplicable manual, ribbon core and roll limits, and the approved coated side.
Printed resultRepresentative output from the actual stock, ribbon and production job.

Work through a width example

Suppose a fictional label face is 48 mm wide on a 54 mm liner. A 50 mm ribbon covers the face on a centered drawing but cannot cover the entire 54 mm web. A 60 mm candidate can cover the web geometrically. The equipment owner still needs to confirm that the printer accepts that ribbon and that the installed path places it over the web. These example widths describe neither a recommended ribbon nor a compatible CYJ stock.

When the web changes, keep the previously approved ribbon part number only if the new combination still satisfies the equipment requirements and sample trial. A wider ribbon may solve coverage but still have the wrong winding, core or formulation. The ribbon consumption guide addresses length and quantity after compatibility is established.

This comparison applies to jobs using thermal transfer ribbon. For direct thermal supply, ask the machine owner to confirm the approved media and print method. For industrial barcode labels, send the printer model, face and web drawing, ribbon reference and quantities so that each candidate label construction can be reviewed against the real machine.
