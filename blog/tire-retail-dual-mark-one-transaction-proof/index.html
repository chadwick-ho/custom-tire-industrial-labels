Dual-Marked Tire Labels: Check That Either Retail Barcode Identifies the Same Item

Published November 12, 2026

A retailer wants a 2D retail barcode alongside the existing EAN/UPC on a tire label. Each symbol reads in isolation. Before approving the new layout, confirm what the retailer’s checkout does when both symbols are visible together.

Confirm the intended trade item and transaction first

Get the approved GTIN and packaging level from the data owner. Record which carriers the retailer accepts and which POS equipment or software configurations will be used. In the source data and proof, compare the meaning of the identifiers using the required representation for each carrier. A format can use a different string length without identifying a different item.

Ask the retailer to test the representative finished label in the applicable lanes. Check both symbol paths in isolation and together, using the approved handling sequence. Compare the expected product record and number of posted events. Keep a scan-to-web check separate if the 2D symbol also provides a customer destination.

The GS1 2D retail implementation guideline discusses dual marking, placement and POS system behavior. Apply the relevant trading-partner rules before approving physical layout.

Review pointEvidence to record before ordering
One itemAssigned GTIN, packaging level and permitted representation for each carrier.
Two capturesExact values decoded, approved data formats and expected item lookup.
Checkout witnessBoth visible on the applied label, relevant scanner or software versions and posted transaction count.

When to release the order

Hold when either path identifies the wrong item or the same presentation posts twice. Have the retailer confirm the release scope across its lanes. If the second code is for a different task, assign distinct expected behavior instead of applying this same-transaction comparison.
