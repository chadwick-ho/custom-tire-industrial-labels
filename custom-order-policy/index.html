Custom Order Policy

Custom tire labels and industrial labels are produced according to project-specific requirements. Specifications should be reviewed and confirmed before production.

Send Your Label RequirementsChat with a Label Specialist

Digital proof before production. Material and adhesive options are discussed according to your application requirements.

Quote Checklist

  • Label type and application
  • Surface and environment
  • Size, shape and quantity
  • Material and adhesive preference
  • Barcode, QR code or variable data
  • Artwork or existing label reference
Send Requirements

Project Specification

Each custom order may depend on label size, shape, quantity, material, adhesive, surface, environment, printing, variable data, finish, roll or sheet format, packaging and shipping requirements.

Artwork Approval

Customers should review and approve artwork, text, barcode placement, QR code placement, serial number format and visual layout before production.

Changes After Approval

Changes after proof approval may affect cost, timing or production feasibility.

Testing and Documentation

If a label requires specific testing or documentation review, the requirement must be provided before order confirmation.
