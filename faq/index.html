FAQ

Questions Buyers Ask

What information do you need for a quote?

Please send your label type, application, size, shape, quantity, surface, material preference, adhesive requirement, indoor or outdoor use, barcode or variable data requirements, roll or sheet format and artwork if available.

Can you make custom tire labels?

Yes. Custom tire labels can be discussed for tire tread, product identification, barcode, QR code, inventory, warehouse and shipping applications.

Can you recommend adhesive options for tire surfaces?

Adhesive options can be discussed according to the actual tire surface, surface texture, labeling process and intended use.

Can you print barcode labels?

Yes. Barcode label printing can be discussed for tire and industrial applications. Please send barcode data, code type and layout requirements.

Do you support variable data printing?

Yes. Variable data label projects can include unique barcodes, QR codes, serial numbers, batch numbers, product codes, model numbers and different text per label.

What is your MOQ?

MOQ depends on the label construction, size and production method. Send us your specification for confirmation.

How long does production take?

Lead time is discussed according to the project specification and order quantity.

Can you handle customer-required documentation?

Please send the required document or standard before ordering so the request can be reviewed against the project specification.
